# RobinCock $RBC — Website

A free static landing page for RobinCock ($RBC), designed for GitHub Pages.

## Before publishing
- Replace `ADD_MAINNET_RBC_MINT_ADDRESS_HERE` with the verified mainnet mint address.
- Replace the X and Telegram placeholder buttons with the real community URLs.
- Confirm every tokenomics, liquidity, and authority claim matches the actual on-chain state.

## GitHub Pages
Upload `index.html` and `robincock-logo.png` to the root of a GitHub repository, then enable Pages from Settings → Pages. GitHub Pages serves static HTML/CSS/JS directly from a repository.
